# Recursos del Curso de Big Data

Este repositorio contiene ejercicios prácticos y recursos utilizados en el curso de Big Data de **Eurecat Academy**.

## Objetivos

El curso se centra en el uso de **Hadoop y PySpark** para:

- Comprender los fundamentos del procesamiento de Big Data.
- Trabajar con grandes volúmenes de datos.
- Realizar procesamiento distribuido.
- Analizar datos estructurados y no estructurados.

## Contenido

El repositorio está organizado en dos bloques principales:

### Hadoop

Incluye recursos y prácticas relacionadas con:

- HDFS y almacenamiento distribuido.
- MapReduce.
- Docker y despliegue de un clúster Hadoop.
- Hive.
- Ejercicios prácticos de procesamiento y análisis de datos.

### PySpark

Incluye notebooks y ejercicios sobre:

- Primeros pasos con Python.
- Introducción a PySpark.
- DataFrames.
- Procesamiento y análisis de datos.
- Regresión y regresión logística.
- K-Means.
- Visualización de datos.
- Análisis de texto.
