# Conjunto de datos

Esta carpeta contiene el archivo `BigData_Custom_Sample.csv`, utilizado en las prácticas de Hadoop y Hive del curso.

## Descripción

El conjunto de datos contiene **200 registros ficticios** creados exclusivamente con fines educativos.

Cada registro incluye las siguientes columnas:

| Columna | Descripción |
|---|---|
| `id` | Identificador único del registro |
| `edad` | Edad de la persona |
| `sexo` | Sexo reportado |
| `pais_donde_vive` | País de residencia |
| `opinion_big_data` | Breve opinión sobre Big Data |

## Uso

Los datos son completamente simulados y no contienen información personal real.

Se utilizan para practicar:

- carga y almacenamiento de datos;
- creación de tablas en Hive;
- consultas SQL;
- filtros, agregaciones y análisis básicos.

El objetivo es trabajar con datos en un entorno controlado sin utilizar información sensible.
